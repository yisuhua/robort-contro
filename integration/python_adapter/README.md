# Reserved interface only — PROPOSED / NOT CONNECTED

The independent disassembly-direction project remains isolated. `contract_v1.schema.json`
defines an optional future data message, **not an implemented ROS publisher,
service, direction-generation algorithm, planning routine, or safety layer**.
The schema has no authority to change Stage 1-2 joint axes or geometry.
A later integration must explicitly define transport, data validation, frames,
q-order, units, failure handling and a versioned adapter before execution.
