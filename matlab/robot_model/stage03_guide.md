# 第三课：逆运动学与末端笛卡尔直线轨迹

**阶段状态：PROPOSED / MATLAB NOT RUN。** 只保留第一课已确认的运动学参数；全部末端轨迹输入、示范角度和数值求解限值为本课新设的教学测试条件，不属于实际机器人机械限位或定位性能。

## 准备与运行
1. 打开本地 GitHub 仓库 `yisuhua/robort-contro`。
2. 在 MATLAB 打开同一个目录下的 `build_robot.m` 和 `stage03_inverse_kinematics.m`。
3. **先运行** `build_robot.m`，在工作区确认 `robot` 存在，且打印零位法兰 `[0.9000 0 0.3200]`。
4. **再运行** `stage03_inverse_kinematics.m`。运行之间不要执行 `clear`。
5. 程序首先验证目标单点，然后生成 31 个直线位置目标，求逐点逆解、回代验证，再绘图、播放动画。任何目标未达到指定阈值都报错停止；不要删除校验或降低精度“修复”失败。

## 数学思路
- 正运动学：`T=FK(q)`，输入六轴角度 `q`，输出 4×4 末端齐次变换。
- 逆运动学：给定目标 `T_d`，由 `inverseKinematics` 求 `q` 满足 `FK(q)≈T_d`。
- 起点设为一个**非零参考关节角**（单位度）：`[15;-25;35;10;30;-15]`。先正解出起点位姿，避免在所有关节零位、腕部奇异的构型上开始 IK。
- 终点沿世界 XYZ 方向相对起点平移 `[+15;-10;+18]` mm，**保持末端姿态不变**。
- 归一化插值参数 `u ∈ [0,1]`，`s(u)=3u²-2u³`。因 `p_d(u)=p_start+s(u)Δp`，在三维空间中的几何轨迹是一条直线。它不是基于真实时间的运动控制指令。
- 求解器权重 `[1 1 1 1 1 1]`：**前三项为姿态误差权重，后三项为位置误差权重**。权重只影响数值求解优先级，不对应力矩。
- 第 i 个点用第 i−1 个点的解作为初始猜测，以帮助关节解支连续。
- 真正能否到达目标，依据 **正运动学回代** 的独立位置误差和旋转角误差判断，不仅检查求解器 `Status`。

## 本课预设数值验收（学习用，不是工程性能）
- 逆解求解器每点 `Status = 'success'`。
- 单点和全部采样点位置误差 `< 1e-4 m = 0.1 mm`。
- 旋转角误差 `< 1e-3 rad ≈ 0.0573°`。
- 相邻采样点最大单关节变化 `< 0.15 rad`，仅用于检出 IK 解支跳变；不是速度和真实关节极限验收。
- 无论是否通过，以上数值不代表设计目标中的 ±0.03 mm 重复定位精度已经实现。

## 理论几何核对（独立于 MATLAB）
采用相同的六轴串联变换，在参考姿态下，起点法兰位置近似
`(0.800535, 0.226188, 0.326286)` m，
终点期望位置近似
`(0.815535, 0.216188, 0.344286)` m。
给定段长 `||Δp||≈0.0254755 m`。
使用独立 Python/Scipy 连续多点非线性最小二乘的**概念验证**，相同位姿约束可在附近关节构型求解；这不是 MATLAB 内置 IK 求解器的运行证据或性能结论。实际 MATLAB 以本机结果为准。

## 已知边界
- 逆运动学有多解，局部迭代求解不保证针对任意目标成功。
- 目前候选机械臂的详细关节轴线仍需与 CAD 对照；J2~J6 真实限位未明确，因此所用示范角度不能视为已认证安全姿态。
- 本课不检查外壳碰撞、障碍物、奇异附近条件数、关节速度与加速度上限、力矩、质量惯量、控制器和 ROS。
- `show(...,'Frames','off')` 使用上一节在本机通过的选项集合，避免此前无效的 `'all'`。
- 如出错，保留 MATLAB 完整输出；不得事后更改验收阈值来制造 PASS。
